\# Smart Campus ERP – College Administration System



\## Project Overview



Smart Campus ERP is a college administration demo designed to organize student records, faculty information, course details, attendance, and examination records in one interface.



\## Live Demo



https://meenu1012.github.io/Smart-Campus-ERP/



\## Technologies Used



\* SAP ABAP – sample reports and class source files

\* HTML

\* CSS

\* JavaScript

\* Git and GitHub

\* GitHub Pages



\## Modules



1\. Dashboard

2\. Student Management

3\. Faculty Management

4\. Course Management

5\. Attendance Management

6\. Examination Management



\## Project Structure



\* `src/reports/` – ABAP report source files

\* `src/classes/` – ABAP class source file

\* `database-design/` – database table design

\* `documentation/` – project and testing documentation

\* `web-demo/` – browser-based demonstration

\* `screenshots/` – project screenshots



\## How to Run the Web Demo



Open `web-demo/index.html` in a browser, or visit the live demo link above.



\## Important Note



The deployed website is a frontend demonstration that stores sample records in browser storage. It is not connected to a shared database or a live SAP system. The ABAP source files require testing in a compatible SAP environment.
